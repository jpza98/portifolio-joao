01. // sobre mim

Código limpo, sistemas escaláveis.

Sou Sênior Full Stack Software Engineer com mais de 4 anos de experiência em ambientes ágeis. Hoje a linguagem com que mais trabalho é PHP, desenvolvendo módulos e APIs para o SEI. Também tenho base forte em backend Java com Spring Boot e microsserviços, e em frontend com React, Next.js, TypeScript e Angular 17. Gosto de conduzir demandas de ponta a ponta — do refinamento à implantação.

Hoje atuo pela Basis Tecnologia no TRF2 — Tribunal Regional Federal da 2ª Região, trabalhando no ecossistema do SEI: o MODJUS (React + Next.js + Node), um módulo PHP de API REST para o SEI, IA com RAG no SEI Criar, a integração com a Apoia da PDPJ/CNJ e a migração para OpenShift.

Antes, na Tardis Tecnologia, entreguei sistemas enterprise para Caixa, Bradesco, Santander, Itaú (iCarros), BRB, CNH e Correios, além de integrações com Adquirentes e BaaS na fintech Shield Tecnologia.
